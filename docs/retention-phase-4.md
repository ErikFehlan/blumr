# Stage 4: feedback impact and useful reminders

The search overview includes a single collapsed “Feedback applied · View changes” line beside the shortlist. Opening it shows the latest saved approval for each affected candidate: Manager Fit and JD Fit before/after, unchanged scores, recommendation changes, and the assessment explanation. Candidate links use IDs. Only a matching durable approval audit with saved feedback sources qualifies; pending proposals and untraceable legacy results cannot claim an applied change. This view makes no additional AI calls.

Feedback quotations and applied lesson text are snapshotted from validated server-selected sources when the assessment is prepared. They never resolve against a later edit or use model-written quotations. Approved lessons and automatic historical context remain distinguishable. Details stay collapsed by default, preserve expansion during polling, and are dismissible. Dismissals store only approval identifiers in this browser, scoped to user, workspace, and job; a later approval appears again.

Notifications now check the current task revision/status, active job, and saved preferences. Completed or replaced work remains in history but leaves the unread count. Assessment updates and processing failures group by search and category; completed assessments retain quiet delivery. Existing notification settings remain authoritative.

Existing opted-in onboarding reminders now target unfinished work in an active search after 24 hours: a grouped assessment review or an empty search waiting for candidates. Empty accounts and completed/closed searches produce no reminder. Messages link to the relevant workspace, job, and (for one review) candidate after sign-in. Membership is checked before honoring a workspace link. Invalid or closed destinations fall back to Home. Existing weekly claims, provider idempotency, opt-out checks, and admin/manual controls remain intact; this release does not enable recipients or send test email.

Validation includes application tests for audit/source matching, escaping, unchanged scores, notification grouping, reminder content, and deployment source/permission checks; PostgreSQL tests for current-task filtering, private/member access, weekly deduplication, preferences, and stale/completed/closed work; and browser tests for compact default, expansion, candidate identity, job isolation, dismissal/reload/new approvals, reminder links, and 320/390px dark/light layouts. The new SQL and browser journeys run in the required release workflow.
